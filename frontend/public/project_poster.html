1. Abstract & Executive Summary

Conducting academic examinations for university programming curricula faces critical bottlenecks: manual grading subjectivity, delayed feedback loops (7–15 days), severe vulnerability to tab-switching malpractice, and massive paper consumption.

This project presents SOU SmartExam, an enterprise-grade cloud examination system that unifies Automated MCQ assessment and Practical Coding Exams. Powered by Google Gemini 1.5 Flash and an intelligent AST construct decompiler, it delivers instantaneous, transparent, construct-level evaluation with zero line-length bias.

⚠️

2. Problem Statement

  • Manual Grading Latency: University professors spend 15–20 minutes manually reviewing each code submission, resulting in delayed academic grades.
  • Evaluator Inconsistency: Variations in faculty strictness lead to subjective penalties for equivalent algorithmic solutions.
  • Absence of Granular Feedback: Standard autograders provide binary pass/fail without explaining which code construct caused the deduction.
  • Exam Security Loopholes: Unproctored student browser sessions allow illicit clipboard usage, external tab lookups, and developer console cheating.
  • Environmental Impact: 100,000+ paper answer booklets consumed every semester during university tests.
🎯

3. Research & Project Objectives

  • Dual-Track Assessment Engine: Unify objective MCQs and practical coding examinations in a centralized student portal.
  • Construct-by-Construct Grading: Automatically decompose submissions into interface signature, guard conditions, core iteration loops, and return outputs.
  • Strict Anti-Cheating System: Enforce 3-strike tab detection, window-blur alerts, fullscreen lockdown, and selective clipboard control.
  • Zero-Length Algorithmic Equity: Ensure concise 1-line functional/recursive code receives full marks equal to verbose solutions.
  • Instant Ground-Truth Generation: Synthesize working reference solutions and automated testcases dynamically upon question upload.

6. Key Innovation: Construct-Level Code Decomposition

Unlike traditional black-box platforms that assign 0 marks if a single stdout character differs, our intelligent engine parses the student's code into granular functional blocks and distributes the question's total marks:

// PROBLEM: Factorial with Negative Edge-Case Handling [Total: 45 Marks]
function factorial(num) { Interface Verified
if (num < 0) return "Undefined"; 22 Marks Awarded
let result = 1;
for (let i = 2; i <= num; i++) result *= i; 23 Marks Awarded
return result;
}
console.log(factorial(5)); // Output: 120 (Verified 100%)
✅ Total Score: 45 / 45 Marks [Condition: 22/22 + Loop: 23/23]
Fault-Tolerant Partial Credit: If a student misses the negative guard condition if (num < 0), only 22 marks are deducted; the correct iteration loop preserves 23/45 marks automatically.
🛡️

7. Proctoring & Academic Integrity Safeguards

3-Strike Tab Guard:

Instant detection of browser blur / tab switching. Displays interactive modal warning; 3rd violation triggers automatic disqualification.

Full-Screen Lock & Clipboard:

Permits legitimate in-editor copy-paste while preventing unauthorized external paste dumps, context menus, and developer tools inspection.
